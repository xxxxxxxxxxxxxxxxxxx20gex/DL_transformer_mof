## 3. MOFormer 架构与输入（正文 Methods）


| 项                     | 设定                                                                                                        |
| --------------------- | --------------------------------------------------------------------------------------------------------- |
| Transformer **编码器层数** | **6**（3 层版本在 QMOF 上精度更低，见 **Table S4**）                                                                   |
| 序列长度                  | **512**（超长截断，不足 padding）；QMOF 无超长；hMOF 约 **0.37%** token 化后超过 512                                         |
| 嵌入维度 d_{emb}          | **512**（位置编码公式中）                                                                                          |
| 输入表示                  | **MOFid**（SBU 为 SMILES，拓扑/穿插为 RCSR 编码；tokenizer 为改进 SMILES + 拓扑分词，`&` 连接两段；BERT 风格 **[CLS]** / **[SEP]**） |
| 下游回归                  | 使用 **[CLS]** 对应 embedding 接 **MLP**                                                                       |
| 非 DL baseline         | **XGBoost** + SOAP / Stoichiometric-120 / **RACs**（RACs 来自 **mofdscribe**）                                |

## 4. 自监督预训练与微调（正文）


| 项                  | 设定                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| 预训练数据              | CoRE MOF 2019 + hMOF + Boyd&Woo；仅保留**同时有 3D 结构与 MOFid** 的样本；**去重 MOFid** 后 **413 535** 个唯一 MOF |

## 5. 其它 baseline 细节（便于对齐实验）


| 方法                     | 说明                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| **SOAP**               | 结构基特征；每 MOF 的 SOAP 矩阵经 **inner average** 压成单向量；参数 **Table S5**；hMOF 上特征维度 **2772**，QMOF 上 **19 908**（同参） |
| **Stoichiometric-120** | 基于化学式统计的结构无关特征                                                                                           |
| **RACs**               | 基于晶体图与原子属性，**不依赖 3D 笛卡尔坐标**，视作结构无关描述符                                                                    |

## 6. 数据效率实验（正文 Figure 5，数值见原图）

- **任务**：QMOF 带隙；hMOF 上 **CO₂ 0.5 bar** 吸附。  
- **做法**：从训练集抽子集 **{100, 500, 1000, 5000, 10000, 50000}**（hMOF 可到 50k）；**验证集与测试集固定不变**。  
- **QMOF 上 MOFormer**：因带 MOFid 的 QMOF **不足 7500**，最大子集规模为 **5000**。  
- 每点 **3 次**不同种子随机子集，取平均。

## 8. 论文中报告的相对改进（便于对比叙述）

- **QMOF 带隙**：预训练使 CGCNN MAE 降 **6.79%**，MOFormer 降 **5.34%**（相对各自 scratch）。  
- **hMOF 吸附（多压力平均）**：预训练使 MOFormer 约 **4.3%**、CGCNN 约 **16.5%**。  
- 结论段汇总：相对 Stoichiometric-120 / RACs，MOFormer 在带隙上约 **21.4% / 16.9%** 更高精度；吸附任务上约 **35–48% / 25–42%**（相对 Stoichiometric-120 / RACs）。
